# Project Notes

- Production deploys for this project go to Vercel: `https://hebrew-study-helper.vercel.app/`.
- Use `npm run deploy:prod` for production deploys.
- Do not deploy this project with OpenAI Sites or `*.chatgpt.site` unless the user explicitly asks for that target. The `.openai/hosting.json` file is not the production deployment source of truth for this repo.
